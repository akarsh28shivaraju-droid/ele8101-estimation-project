## Project Summary
This repository contains the group coursework for the ELE8101 Controls module. The project focuses on designing and validating estimators for vehicle position and velocity using beacon-based distance measurements.

## Repository Structure
- 'src/': source code
- 'results/': plots, outputs, and simulation results
- 'report/': report files
- 'meetings/': meeting notes and collaboration records
